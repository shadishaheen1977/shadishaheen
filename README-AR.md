# موقع شادي شاهين — خطوات الرفع وربط الدومين

## رفع الملفات إلى GitHub

1. أنشئ مستودعاً جديداً على GitHub، واختر اسم الفرع `main`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، بما فيها المجلد المخفي `.github`.
3. من المستودع افتح **Settings → Pages**، واجعل **Source** هو **GitHub Actions**.
4. افتح تبويب **Actions** وانتظر اكتمال مهمة **Deploy portfolio to GitHub Pages**. سيُنشر الموقع تلقائياً مع كل تحديث على `main`.

## ربط دومين خاص

1. في **Settings → Pages → Custom domain** أدخل الدومين الذي تملكه، مثل `example.com` أو `www.example.com`، ثم اضغط **Save**.
2. من لوحة شركة الدومين أضف سجلات DNS المناسبة:

   - للدومين الأساسي مثل `example.com`: أضف سجلات `A` باسم `@` إلى العناوين الأربعة التالية:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - لـ `www.example.com`: أضف سجل `CNAME` باسم `www` يشير إلى `USERNAME.github.io`، مع استبدال `USERNAME` باسم حساب GitHub أو المؤسسة المالكة للموقع.
   - إذا كانت لوحة DNS تطلب دعم IPv6، أضف أيضاً سجلات `AAAA` من [إرشادات GitHub الرسمية](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

3. احذف سجلات `A` أو `AAAA` القديمة المتعارضة للدومين. قد يحتاج انتشار DNS حتى 24 ساعة.
4. بعد ظهور الموقع على الدومين، ارجع إلى **Settings → Pages** وفعّل **Enforce HTTPS** عندما يصبح الخيار متاحاً.

> لا ترفع مجلد `node_modules`. ملف النشر ينشئ نسخة الموقع تلقائياً، لذلك يكفي رفع ملفات المشروع ومجلد `.github`.

## إضافة فيديوهات التمثيل

أضف مقاطعك من صفحة الإدارة `#/admin` واختر تصنيف `acting`، أو أضف عناصر الفيديو مباشرة في `src/data/portfolio.ts`. لا يحتوي الملف الأصلي على مقاطع تمثيل، لذلك يظهر التصنيف حالياً مع رسالة «ستُضاف قريباً».
